Vercel Fallback Page

Movie Platform

This repository now serves a valid page on Vercel instead of a raw 404: NOT_FOUND. The full application is a Spring Boot server with file-based storage, so it needs a Java or Docker host for complete functionality.

Why Vercel showed 404

The project did not include a Vercel-compatible static entry point or function route, so Vercel had nothing to serve for the deployment.

What changed

A fallback index.html and vercel.json rewrite now ensure every request resolves to this page instead of failing.

How to run the full app

Use the included Docker setup or the Render Blueprint in render.yaml to deploy the real Spring Boot application.
